[minor/high] src/Weapons/WeaponAnalyzer.cs:2385  Magazine vertices are copied out of the mesh twice, with duplicated code
  what:   MeshPoints (2371-2393) reads `Vector3[] v = m.vertices;` (2385). PrincipalAxis(part, shownNearOnly, ...) repeats the same loop (2400-2417, `m.vertices` at 2411). MagAxisFromShape calls PrincipalAxis(magPart) (2233), and then TopTangent (2248) calls MeshPoints(part, true) (2314) on the same meshes.   why:    m.vertices returns a new managed copy of the whole vertex array on every read. For an elongated magazine that is two full copies, and four when the near-only set is too small.   change: Collect the magazine's points once in MagAxisFromShape and pass the list to both PrincipalAxis and TopTangent (change their signatures to take the points). Delete the copy-pasted loop at 2400-2417 and call MeshPoints instead. If this Unity build has the Mesh.GetVertices(List<Vector3>) overload (not checked here), read into a reused list rather than m.vertices.

[tiny/medium] src/Weapons/WeaponAnalyzer.cs:3343  GunMeshHost compares every bone pair with IsChildOf
  what:   In GunMeshHost, for each skinned renderer: `foreach (Transform b in gunSet) { foreach (Transform other in gunSet) { if (other.IsChildOf(b)) count++; } int depth = Depth(b, root); ... }` (lines 3338-3348).
  why:    This is B squared IsChildOf calls per skinned renderer, each a parent walk, plus a Depth walk per bone. A gun with 30-60 bones costs well under 1 ms. A heavily rigged mod with several hundred bones could cost tens of milliseconds per renderer, inside the one-time analysis.
  change: Count descendants in one pass. For each `other` in gunSet, walk its ancestors once and increment a Dictionary<Transform,int> for each ancestor that is in gunSet. IsChildOf is also true for the transform itself, so keep the self count. This makes the pass O(B times depth).
