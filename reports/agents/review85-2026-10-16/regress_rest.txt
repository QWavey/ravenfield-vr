[minor/medium] src/Weapons/DrivingWeapons.cs:91  Armed car driver keeps a drawn gun when switching seats into a gunner seat
  what:   Harmony postfix on Seat.CanUsePersonalWeapons (DrivingWeapons.cs:91): `if (!__result && DrivingWeapons.Armed && __instance.occupant != null && __instance.occupant == GameContext.PlayerActor) __result = true;`. It applies to every seat, not only the seat the weapon was drawn in. Commit b0a99c2 (DrivingWeapons.cs:21-33, HasGun) lets a car driver be Armed for the first time, because the horn no longer blocks CanDraw. Actor.SwitchSeat (Actor.cs:2776-2800) runs LeaveSeatForSwap() and EnterSeat(seat) in one call, and Armed is only cleared by UpdateDrivingWeapons next frame (WeaponSystem.cs:503-513). In EnterSeat, SetOccupant (Actor.cs:2519) and StartSeated (Actor.cs:2524) run before `if (!seat.CanUsePersonalWeapons() && activeWeapon != null) HolsterActiveWeapon();` (Actor.cs:2526).
  why:    Reproduce: drive a car, draw the pistol from a holster, press the keyboard Seat2 bind (FpsActorController.cs:1618; the bridge merges keyboard results, GameInputBridge.cs SteelInputGetButtonDownPatch) to move into a gunner seat. The postfix reports CanUsePersonalWeapons() true for the gunner seat, so (1) the pistol is not holstered at Actor.cs:2526, and Actor.Unholster (Actor.cs:2321-2331) then sets activeWeapon to the machine gun without calling Holster() on the pistol, leaving the pistol active and unholstered; (2) FpsActorController.StartSeated (FpsActorController.cs:758-771) takes the personal-weapon branch and skips HideFpModel() and the seat aim FOV, so the first-person arms and gun model can stay visible in the gunner seat. Before b0a99c2 a car driver always had its horn, so this path was reached only from passenger seats (the same defect, already present there).
  change: Remember the seat the weapon was drawn in. In DrivingWeapons add `private static Seat _armedSeat;` and a public `ArmedSeat` getter; set `_armedSeat = actor.seat;` in Draw(); clear it in Reset() and PutAway(). Change the postfix to `if (!__result && DrivingWeapons.Armed && __instance == DrivingWeapons.ArmedSeat && __instance.occupant == GameContext.PlayerActor) __result = true;`. In UpdateDrivingWeapons (WeaponSystem.cs:503-513), if Armed and actor.seat != ArmedSeat, call Reset() so a seat change the mod did not make also ends the armed state. A passenger-to-passenger swap still works, and a swap into a gun seat holsters the pistol at Actor.cs:2526.
