#1 [major] [medium] Reload EmitParticles events count as "played", so a manual action can be silent and skip the donor and synth fallback
   where: src/Weapons/WeaponSounds.cs:77-87 (Play), :118-121 (PlayCue Event branch), :166-171 (SendEvent)
   trigger: A weapon's reload animation has an EmitParticles animation event (casing emitter, typically at slide back) that falls in the matching window of a MagOut/MagIn/SlideBack/SlideForward keyframe, and no sound-bank clip or slice was bound to that same keyframe. The player performs that manual action.
   effect: Play() gets played=true from PlayCue(), returns early, and no audio is played. SoundDonors.Find (line 90) and the ProceduralSounds fallback (line 96) are never reached. The action is silent. The particle emit only happens if the emitter sits on the animator object, because SendMessage uses DontRequireReceiver.
   evidence: WeaponSounds.cs:79-84 loops the cues with played |= PlayCue(cue) and returns when played. :121 sends Event cues without Clips to SendEvent. :170-171 case "EmitParticles" calls target.SendMessage and returns true unconditionally. Trace hop (locked file, read only, not reported): PoseSampler.cs:37 whitelists EmitParticles; WeaponAnalyzer MatchCues binds every reload event to the nearest keyframe in [-0.15, +0.6] s, so a particle event can become that keyframe's only cue.
   fix idea: Return false from SendEvent for EmitParticles (or count only sound-producing cues as played) so the donor and synth still play for that action. Do not bind EmitParticles to MechSound kinds.
   confidence note: medium. The code path is certain; whether a real asset has such an event near these keyframes cannot be checked from the repo.

#2 [minor] [medium] Default pouch zone contains the centre of the off-hip gear/handgun holster

   trigger: Default settings (Boneworks layout, pouch on off hip). The GearOff spot is filled (three gear items), or in the classic layout a second hand weapon sits in HandgunOff (:388). The player holds a gun in the dominant hand in Manual reload mode and squeezes the free hand at that holster.
   effect: Computed from the formulas: pouch = belt - 0.10*fwd - 0.17*right; OffBeltFront = belt - 0.09*right.    evidence: BodyZones.cs:98-125 and Position() at :368-393; HolsterAt uses HolsterRadius 0.2 (:246, :255). The contradiction with the comment at :121 is direct.
   fix idea: Move the default pouch point at least HolsterRadius from the off-hip spots, or make PouchRadius plus HolsterRadius smaller than the centre distance so the zones are disjoint.
   confidence note: medium.

#8 [tiny] [low] AudioSlicing clamp can stretch a short slice past its window
